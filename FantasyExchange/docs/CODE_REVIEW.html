Sequential search

for (Player p : players) {
    if (p.getName()
        .equalsIgnoreCase(name)) {
        return p;
    }
}
return null;

Average and worst case: O(n) comparisons.

Recursive price sort

Split the list in half until each part has fewer than two players.

Merge sorted halves using two indices. Copy whichever list still has items.

O(n log n) time
O(n) peak extra space

Equal prices take the left item first, preserving order.
